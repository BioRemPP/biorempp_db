# BioRemPP Database Analysis

## Overview

This directory contains scripts for performing comprehensive exploratory data analysis on the generated BioRemPP database. The analysis generates detailed statistics, metadata, and summaries in JSON format for use in official documentation.

## Files

- **`analyze_database.R`** - Main analysis script
- **`output/`** - Directory containing generated JSON files (created after running the script)

## Requirements

### R Packages

```r
install.packages(c("dplyr", "jsonlite", "stringr", "tidyr"))
```

## How to Run

### Prerequisites

1. Ensure the database has been generated by running `../generate_database.R`
2. The database file should exist at: `../output_data/biorempp_database_v1.0.0.csv`

### Execution

#### Option 1: RStudio

1. Open `analyze_database.R` in RStudio
2. Click "Source" or press `Ctrl+Shift+S`

#### Option 2: R Console

```r
setwd("path/to/project/root/analysis")
source("analyze_database.R")
```

#### Option 3: Command Line

```bash
cd "path/to/project/root/analysis"
Rscript analyze_database.R
```

## Output Files

The script generates 9 JSON files in the `output/` directory:

### 1. `database_metadata.json`
Complete metadata about the database including:
- Database information (name, version, date)
- Data sources
- Schema description
- Data quality metrics

### 2. `basic_statistics.json`
Fundamental statistics:
- Total entries and columns
- Unique counts for all dimensions
- Missing value counts

### 3. `compound_statistics.json`
Detailed compound analysis:
- Compounds per class
- Compounds per agency
- Top 20 most frequent compounds
- Class distribution summary

### 4. `ko_statistics.json`
KEGG Orthology analysis:
- Top 20 most frequent KO entries
- KO frequency distribution
- Compounds per KO summary

### 5. `enzyme_statistics.json`
Enzyme activity analysis:
- Top 30 most frequent enzymes
- Enzyme frequency distribution
- Unique compounds and KO per enzyme

### 6. `gene_statistics.json`
Gene information analysis:
- Top 20 gene symbols
- Top 20 gene names
- Frequency distributions

### 7. `crosstab_statistics.json`
Cross-dimensional analysis:
- Top 20 class-agency combinations
- Top 20 enzyme-class combinations
- Top 10 classes by KO diversity

### 8. `executive_summary.json`
High-level summary for documentation:
- Overview statistics
- Key highlights
- Coverage metrics

### 9. `complete_analysis.json`
All analysis results combined in a single file

## Using the JSON Output

The generated JSON files can be used for:

1. **Documentation**: Import statistics into official documentation
2. **Visualization**: Create charts and graphs using the data
3. **Quality Assurance**: Monitor data quality metrics
4. **Reporting**: Generate automated reports
5. **API Integration**: Serve metadata via API endpoints

### Example: Reading JSON in R

```r
library(jsonlite)

# Read metadata
metadata <- fromJSON("output/database_metadata.json")

# Read executive summary
summary <- fromJSON("output/executive_summary.json")

# Access specific values
total_entries <- summary$overview$total_entries
most_frequent_enzyme <- summary$highlights$most_frequent_enzyme
```

### Example: Reading JSON in Python

```python
import json

# Read metadata
with open('output/database_metadata.json', 'r') as f:
    metadata = json.load(f)

# Read executive summary
with open('output/executive_summary.json', 'r') as f:
    summary = json.load(f)

# Access specific values
total_entries = summary['overview']['total_entries']
most_frequent_enzyme = summary['highlights']['most_frequent_enzyme']
```

## Troubleshooting

### Problem: "Database file not found"
**Solution**: Run `../generate_database.R` first to create the database

### Problem: "Missing required packages"
**Solution**: Install missing packages with:
```r
install.packages(c("dplyr", "jsonlite", "stringr", "tidyr"))
```

### Problem: JSON files not created
**Solution**: Check that you have write permissions in the analysis directory
