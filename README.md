# BioRemPP Database v1.0.0

**A FAIR-compliant resource integrating KEGG orthology, environmental agencies, and curated biodegradation data for bioremediation research.**

---

## Overview

The BioRemPP Database (Bioremediation Potential Profile Database) is a curated, integrated resource linking chemical compounds, genes, enzymes, and regulatory frameworks for environmental bioremediation research. The current release contains **10,871 entries** linking **384 compounds** to **1,542 KO identifiers** across **12 chemical classes** and **9 environmental agencies**.

The database is generated by a reproducible **Snakemake workflow** with 18 rules across four layers: preflight validation, data generation (ETL), statistical analysis, and provenance reporting. The pipeline is fully containerized via Docker for reproducibility.

## Quick Start

### Option 1: Docker (Recommended)

```bash
cd biorempp_snakemake_version
docker compose -f env/docker-compose.yml build
docker compose -f env/docker-compose.yml run --rm snakemake
```

### Option 2: Local Snakemake

```bash
cd biorempp_snakemake_version
snakemake --snakefile Snakefile --configfile config/config.yaml --cores 2
```

### Dry Run (Validate DAG)

```bash
cd biorempp_snakemake_version
snakemake -n --snakefile Snakefile --configfile config/config.yaml
```

## Pipeline Architecture

The Snakemake pipeline executes 18 rules in a four-layer architecture:

1. **Preflight** — Validates all 6 input files exist
2. **Generation** — Loads local data + KEGG API, merges relationships, classifies compounds, enriches gene info, extracts enzymes, exports CSV/XLSX
3. **Analysis** — Produces 9 JSON statistical reports (parallelizable)
4. **Reporting** — Computes SHA-256 checksums for all artifacts

### Database Files

| File | Format | Content |
|------|--------|---------|

| Column | Description | Example |
|--------|-------------|---------|
| `cpd` | KEGG Compound ID | `C06790` |
| `compoundclass` | Chemical classification | `Chlorinated` |
| `ko` | KEGG Orthology ID | `K07408` |
| `referenceAG` | Environmental agency | `EPA` |
| `compoundname` | Compound name | `Trichloroethene` |
| `genesymbol` | Gene symbol | `CYP2E1` |
| `genename` | Gene functional description | `cytochrome P450 family 2 subfamily E` |
| `enzyme_activity` | Extracted enzyme activity | `cytochrome P450` |
