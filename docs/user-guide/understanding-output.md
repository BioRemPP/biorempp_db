# Understanding Output

This document explains how to interpret the outputs generated by the BioRemPP Database pipeline.

---

## Overview of Output Structure

The BioRemPP Database pipeline generates three categories of outputs:

### Primary Database Outputs

- **Main database files** (CSV and Excel formats)
- Single denormalized table with 8 columns
- Complete compound-gene-enzyme relationships
- 100% field completeness

### Optional Analysis Outputs

- **9 JSON statistical reports** (generated by `analysis/analyze_database.R`)
- Metadata, summary statistics, cross-tabulations
- Publication-ready metrics

### Log Outputs

- **Console messages** during execution
- Progress indicators, warnings, summary statistics
- Diagnostic information for troubleshooting

**Location:** All outputs are saved in `output_data/` directory (database files) and `analysis/output/` directory (statistical reports).

## Explanation of Key Columns and Fields

The database uses a **flat denormalized schema** where each row represents a single **compound-gene-enzyme-agency** relationship. This design optimizes for analytical queries while maintaining data clarity.

### Column 1: `cpd` (Compound Identifier)

**Data type:** Character

**Format:** KEGG Compound ID (`C#####`)

**Example:** `C06790`

**Semantic meaning:** Uniquely identifies the chemical compound of interest. Maps directly to KEGG Compound database for structural information, pathways, and cross-references.

**Interpretation:**

- Each unique `cpd` value represents one environmental contaminant or xenobiotic compound
- Compounds may appear in **multiple rows** if they are associated with multiple genes, enzymes, or agencies
- To count unique compounds: `length(unique(db$cpd))` → 384 compounds

**Typical use:**

- **Filter by compound:** Find all genes/enzymes associated with trichloroethene (`C06790`)
- **Cross-reference structures:** Look up chemical structure at https://www.kegg.jp/entry/C06790
- **Link to pathways:** Identify metabolic pathways containing the compound

---

### Column 2: `compoundclass` (Chemical Classification)

**Data type:** Character

**Format:** Free text (standardized categories)

**Example:** `Aromatic`, `Chlorinated`, `Polyaromatic`

**Semantic meaning:** Describes the chemical structural class of the compound based on functional groups and molecular architecture.

**Interpretation:**

- **Single or multiple classes:** Some compounds have multiple classifications (e.g., "Aromatic" and "Chlorinated")
- **Enables filtering by chemistry:** Group compounds by shared structural features
- **12 standardized classes:** Aliphatic, Aromatic, Polyaromatic, Chlorinated, Nitrogen-containing, Heterocyclic, Organometallic, Sulfur-containing, Oxygen-containing, Pharmaceutical, Pesticide, Industrial

**Typical use:**

- **Filter by class:** Extract all chlorinated compounds (`db[db$compoundclass == "Chlorinated", ]`)
- **Class-specific analysis:** Compare enzyme diversity across aromatic vs. aliphatic compounds
- **Risk assessment:** Prioritize compounds in high-concern categories (e.g., IARC carcinogens + Chlorinated)

---

### Column 3: `ko` (KEGG Orthology Identifier)

**Data type:** Character

**Format:** KEGG Orthology ID (`K#####`)

**Example:** `K07408`

**Semantic meaning:** Identifies a functional gene group (ortholog cluster) across organisms. Represents a specific enzymatic or functional role abstracted from individual species.

**Interpretation:**

- **Organism-independent:** KO groups genes with equivalent functions across diverse organisms
- **One-to-many relationship:** One compound can be degraded by multiple KO groups (different enzymes)
- **Many-to-many relationship:** One KO group can act on multiple compounds
- To count unique KO entries: `length(unique(db$ko))` → 1,541 KO groups

**Typical use:**

- **Annotate metagenomes:** Match detected KO IDs from functional annotation tools (HUMAnN3, PICRUSt2) to bioremediation potential
- **Pathway reconstruction:** Link KO groups to KEGG pathways for biodegradation cascades
- **Compare microbial communities:** Quantify KO richness related to specific contaminants

---

### Column 4: `referenceAG` (Reference Agency)

**Data type:** Character

**Format:** Agency code (9 standardized codes)

**Example:** `EPA`, `IARC1`, `ATSDR`

**Semantic meaning:** Indicates which environmental regulatory authority has classified the compound as a priority pollutant or contaminant of concern.

**Interpretation:**

- **Regulatory context:** Provides risk classification and jurisdictional relevance
- **Compounds can appear under multiple agencies:** Overlapping regulatory frameworks
- **9 agencies:** ATSDR, EPA, IARC1, IARC2A, IARC2B, PSL, EPC, WFD, CONAMA

**Typical use:**

- **Regulatory compliance:** Identify compounds regulated by specific agencies (`db[db$referenceAG == "EPA", ]`)
- **Risk prioritization:** Focus on IARC Group 1 carcinogens (`db[db$referenceAG == "IARC1", ]`)
- **Multi-jurisdictional analysis:** Compare compound coverage across US (EPA), EU (WFD, EPC), Brazil (CONAMA)

---

### Column 5: `compoundname` (Compound Name)

**Data type:** Character

**Format:** Free text (standardized KEGG nomenclature)

**Example:** `Trichloroethene`, `Benzene`, `Naphthalene`

**Semantic meaning:** Human-readable common name or IUPAC name for the compound.

**Interpretation:**

- **Primary name only:** Synonyms are removed for consistency
- **384 unique names** corresponding to 384 unique compounds
- **May contain special characters:** Greek letters, numbers, parentheses

**Typical use:**

- **Human-readable reporting:** Generate summaries with compound names instead of KEGG IDs
- **Literature search:** Use compound names to find relevant publications
- **Communication with stakeholders:** Present findings using common chemical names

---

### Column 6: `genesymbol` (Gene Symbol)

**Data type:** Character

**Format:** Standard gene nomenclature (HUGO for human genes, custom for microbial genes)

**Example:** `CYP2E1`, `dmpN`, `nahAc`

**Semantic meaning:** Short abbreviation representing the gene associated with the KO group.

**Interpretation:**

- **1,515 unique gene symbols** representing distinct genetic elements
- **May contain commas:** Some KO groups have multiple gene symbols (isoforms/variants)
- **Not necessarily organism-specific:** Represents canonical gene name for the KO group

**Typical use:**

- **Gene-centric queries:** Find all compounds degraded by cytochrome P450 genes (`CYP*`)
- **Functional genomics:** Link gene symbols to transcriptomic data (RNA-seq)
- **Database cross-referencing:** Map to UniProt, NCBI Gene, or other gene databases

---

### Column 7: `genename` (Gene Functional Description)

**Data type:** Character

**Format:** Free text (KEGG annotation)

**Example:** `cytochrome P450 family 2 subfamily E polypeptide 1`, `dioxygenase`

**Semantic meaning:** Expanded functional description of the gene, often including enzyme class or biochemical role.

**Interpretation:**

- **Human-readable context:** Provides detailed functional annotation beyond gene symbol
- **May contain EC numbers:** Enzyme Commission numbers in brackets `[EC:1.14.13.X]`
- **Variable length:** Can range from short (`dioxygenase`) to long (full protein name)

**Typical use:**

- **Annotation quality control:** Verify gene function matches expected biodegradation role
- **Keyword search:** Filter by functional terms (e.g., "oxygenase", "reductase")
- **Cross-reference to enzyme databases:** Extract EC numbers for BRENDA, ExplorEnz lookups

---

### Column 8: `enzyme_activity` (Extracted Enzyme Activity)

**Data type:** Character

**Format:** Controlled vocabulary (210 standardized terms)

**Example:** `cytochrome P450`, `dioxygenase`, `monooxygenase`, `dehydrogenase`

**Semantic meaning:** Standardized enzyme activity type extracted from `genename` using pattern matching against curated enzyme lexicon.

**Interpretation:**

- **Simplified functional classification:** Normalizes diverse gene names to common enzyme types
- **205 unique enzyme activities** in database
- **Hierarchical grouping:** Enables analysis by enzyme family (e.g., all P450s, all dioxygenases)
- **Fallback to genename:** If no enzyme term is matched, the full genename is used

**Typical use:**

- **Enzyme-centric analysis:** Count occurrences of specific enzyme families
- **Pathway inference:** Identify enzyme combinations required for complete degradation pathways
- **Comparative enzymology:** Compare enzyme diversity across different compound classes

## Interpreting Relationships Between Compounds, Genes, and Enzymes

### One-to-Many Relationships

A single compound can be associated with **multiple genes/enzymes**:

**Example: Trichloroethene (C06790)**

```r
# Filter by compound
tce_entries <- db[db$cpd == "C06790", ]
nrow(tce_entries)  # 564 rows

# Unique enzymes acting on TCE
unique(tce_entries$enzyme_activity)
# [1] "cytochrome P450" "monooxygenase" "dioxygenase" "dehydrogenase" ...
```

**Interpretation:** Trichloroethene can be degraded by multiple enzymatic mechanisms, reflecting diverse microbial strategies for xenobiotic metabolism.

---

### Many-to-One Relationships

Multiple compounds can share the **same gene/enzyme**:

**Example: Cytochrome P450 Family**

```r
# Filter by enzyme
p450_entries <- db[db$enzyme_activity == "cytochrome P450", ]
nrow(p450_entries)  # 2,166 rows

# Unique compounds degraded by P450
length(unique(p450_entries$cpd))  # 35 compounds
```

**Interpretation:** Cytochrome P450 enzymes exhibit broad substrate specificity, acting on diverse xenobiotics (aromatic, chlorinated, pharmaceutical compounds).

---

### Compound-Agency Overlaps

Compounds classified by multiple regulatory agencies:

**Example: Benzene (C00180)**

```r
# Filter by compound
benzene_entries <- db[db$compoundname == "Benzene", ]

# Agencies listing benzene
unique(benzene_entries$referenceAG)
# [1] "EPA" "IARC1" "ATSDR" "PSL" "WFD"
```

**Interpretation:** Benzene is recognized as a priority pollutant across multiple jurisdictions, indicating high environmental and health concern.

---

### Enzyme Family Distributions

Analyzing enzyme diversity per compound class:

```r
# Count enzymes per compound class
library(dplyr)
enzyme_by_class <- db %>%
  group_by(compoundclass, enzyme_activity) %>%
  summarise(count = n(), .groups = "drop") %>%
  arrange(compoundclass, desc(count))

# Top enzyme for aromatic compounds
enzyme_by_class %>% filter(compoundclass == "Aromatic") %>% head(3)
```

**Interpretation:** Aromatic compounds are predominantly degraded by dioxygenases (ring-cleaving enzymes), reflecting known biochemical pathways for aromatic biodegradation.

## Typical Downstream Uses of Outputs

### Use Case 1: Metagenomic Annotation

**Workflow:**

1. Perform functional annotation of metagenome (e.g., HUMAnN3, DRAM)
2. Extract detected KO identifiers
3. Join with BioRemPP Database on `ko` column
4. Summarize bioremediation potential by detected genes

**Example (R):**

```r
# Load metagenome KO annotations
metagenome_kos <- read.csv("metagenome_functional_annotation.csv")

# Join with BioRemPP
library(dplyr)
annotated_potential <- inner_join(
  metagenome_kos, 
  db, 
  by = c("KO_ID" = "ko")
)

# Summarize compounds degradable by community
degradable_compounds <- annotated_potential %>%
  group_by(compoundname) %>%
  summarise(n_genes = n_distinct(ko), .groups = "drop") %>%
  arrange(desc(n_genes))
```

---

### Use Case 2: Risk Assessment

**Workflow:**

1. Identify contaminants detected at site (e.g., GC-MS analysis)
2. Map contaminant names to KEGG Compound IDs
3. Query BioRemPP Database for available biodegradation genes
4. Assess completeness of degradation pathways

**Example (R):**

```r
# Site contaminants
site_contaminants <- c("Trichloroethene", "Benzene", "Naphthalene")

# Find biodegradation genes
db_site <- db[db$compoundname %in% site_contaminants, ]

# Enzyme diversity per contaminant
db_site %>%
  group_by(compoundname) %>%
  summarise(
    n_enzymes = n_distinct(enzyme_activity),
    enzymes = paste(unique(enzyme_activity), collapse = "; ")
  )
```

---

### Use Case 3: Comparative Genomics

**Workflow:**

1. Annotate genomes of multiple isolates with KEGG Orthology
2. Extract KO profiles for each isolate
3. Join with BioRemPP Database
4. Compare biodegradation potential across strains

**Example (Python):**

```python
import pandas as pd

# Load database
db = pd.read_csv("biorempp_database_v1.0.0.csv")

# Load genome annotations (KO lists per isolate)
isolate1_kos = pd.read_csv("isolate1_kos.csv")
isolate2_kos = pd.read_csv("isolate2_kos.csv")

# Annotate with bioremediation potential
isolate1_potential = isolate1_kos.merge(db, left_on="KO", right_on="ko", how="inner")
isolate2_potential = isolate2_kos.merge(db, left_on="KO", right_on="ko", how="inner")

# Compare compound coverage
compounds1 = set(isolate1_potential['compoundname'])
compounds2 = set(isolate2_potential['compoundname'])

print(f"Unique to isolate 1: {compounds1 - compounds2}")
print(f"Unique to isolate 2: {compounds2 - compounds1}")
```

---

### Use Case 4: Regulatory Compliance Reporting

**Workflow:**

1. Extract compounds listed by specific agency (e.g., EPA)
2. Cross-reference with detected genes in environmental sample
3. Generate compliance report

**Example (R):**

```r
# EPA priority pollutants with biodegradation genes
epa_compounds <- db %>%
  filter(referenceAG == "EPA") %>%
  group_by(compoundname, cpd) %>%
  summarise(
    n_genes = n_distinct(ko),
    enzyme_families = n_distinct(enzyme_activity),
    .groups = "drop"
  ) %>%
  arrange(desc(n_genes))

# Export for reporting
write.csv(epa_compounds, "EPA_biodegradation_potential.csv", row.names = FALSE)
```

## Notes on Filtering and Post-Processing

### Filtering by Specific Criteria

**By compound class:**

```r
# Chlorinated compounds only
chlorinated <- db[db$compoundclass == "Chlorinated", ]
```

**By enzyme family:**

```r
# Cytochrome P450 enzymes only
p450 <- db[grepl("cytochrome P450", db$enzyme_activity, ignore.case = TRUE), ]
```

**By multiple agencies:**

```r
# IARC carcinogens (Groups 1, 2A, 2B)
iarc <- db[db$referenceAG %in% c("IARC1", "IARC2A", "IARC2B"), ]
```

---

### Aggregating Data

**Count unique compounds per enzyme:**

```r
library(dplyr)
compound_per_enzyme <- db %>%
  group_by(enzyme_activity) %>%
  summarise(
    n_compounds = n_distinct(cpd),
    n_entries = n()
  ) %>%
  arrange(desc(n_entries))
```

**Count genes per compound class:**

```r
genes_per_class <- db %>%
  group_by(compoundclass) %>%
  summarise(
    n_genes = n_distinct(ko),
    n_compounds = n_distinct(cpd)
  )
```

---

### Handling Multi-Value Fields

**Compounds with multiple classes:**

Some compounds are classified under multiple categories (e.g., "Aromatic" AND "Chlorinated"). Each combination appears as a separate row.

**Example: Extracting all classes for a compound:**

```r
# All classes for trichloroethene
tce_classes <- unique(db$compoundclass[db$cpd == "C06790"])
# May return: "Aromatic" and "Chlorinated" as separate rows
```

**Best practice:** Aggregate classes per compound:

```r
compound_classes <- db %>%
  group_by(cpd, compoundname) %>%
  summarise(classes = paste(unique(compoundclass), collapse = ", "), .groups = "drop")
```

---

### Removing Redundancy

**Duplicate compound-KO pairs** (same compound, same gene, different agencies) can be deduplicated:

```r
# Unique compound-KO relationships
unique_relationships <- db %>%
  distinct(cpd, ko, .keep_all = TRUE)
```

---

### Exporting Subsets

**Export filtered data for specific analyses:**

```r
# Export EPA compounds for external tool
epa_data <- db[db$referenceAG == "EPA", ]
write.csv(epa_data, "biorempp_epa_only.csv", row.names = FALSE)
```
