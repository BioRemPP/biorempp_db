# Technology Stack

_Last updated: 2026-05-31_

## Summary

BioRemPP DB 1.0.0 is a bioinformatics database-generation pipeline built on two runtimes: R 4.4 (data wrangling and KEGG API fetching) orchestrated by Snakemake 8.30.0, and Python 3.11 (validation, caching, documentation). Both runtimes run inside pinned Docker containers with digests locked in Dockerfile `FROM` lines. Documentation is rendered with MkDocs Material and published via Read the Docs.

---

## Languages

**Primary:**
- **R 4.4** — All database-generation scripts (`biorempp_snakemake_version/workflow/scripts/generation/*.R`) and shared library (`biorempp_snakemake_version/workflow/lib/`)
- **Python 3.11** — Snakemake orchestration, KEGG validation scripts (`biorempp_snakemake_version/workflow/scripts/validation/*.py`), and the Great Expectations validation package (`biorempp_validation/`)

**Secondary:**
- **Bash / Shell** — Snakemake `shell:` blocks (inline commands in `.smk` rules), documentation build helper (`scripts/build-docs.sh`)

## Build & Infrastructure

**Containerization:**
- Docker Compose (`biorempp_snakemake_version/env/docker-compose.yml`) defines two services:
  - `snakemake` — R + Python + Snakemake pipeline container
  - `validation` — Python-only Great Expectations container
- Both use `volumes: ../../:/workspace` to mount the repo root into `/workspace`
- Images use digest-pinned `FROM` lines for reproducibility

**System Dependencies (installed in pipeline container):**
- `python3`, `python3-pip`, `python3-dev`, `build-essential`
- `libdatrie-dev`, `libxml2-dev`, `libcurl4-openssl-dev`, `libssl-dev`
- `default-jdk` (required by Snakemake's ILP solver)

**Build tooling (validation container):**
- `setuptools` 82.0.1, `wheel` 0.47.0, `pip-tools` 7.5.3
- Package installed with `--no-deps` after lock file install

## CI/CD

**GitHub Actions:**
- Workflow: `.github/workflows/docs-ci.yml`
- Trigger: pushes and PRs to `main`/`dev` that touch `docs/**`, `mkdocs.yml`, `scripts/build-docs.sh`

- Steps: checkout → install deps (`./scripts/build-docs.sh install`) → build (`./scripts/build-docs.sh build`) → verify `site/` exists → upload artifact (7-day retention)
- No pipeline CI workflow detected; pipeline execution is manual via Docker Compose

## Configuration

**Pipeline config:** `biorempp_snakemake_version/config/config.yaml`
- Version string, I/O paths, output filenames, KEGG base URL + endpoint slugs, analysis parameters, validation thresholds

**Validation config:** `biorempp_validation/config/validation.yaml`
- Policy flags (`fail_on_critical`, `fail_on_warning`), validation modes, CSV delimiter, path roots, database contract (expected columns, agencies, compound classes), drift thresholds

**Environment variables (overridable at runtime):**
- `BIOREMPP_API_MAX_RETRIES` (default: 6)
- `BIOREMPP_API_TIMEOUT_SECONDS` (default: 90)
- `BIOREMPP_API_BACKOFF_BASE_SECONDS` (default: 1.0)
- `BIOREMPP_API_BACKOFF_MAX_SECONDS` (default: 30.0)
- `BIOREMPP_API_BACKOFF_JITTER_RATIO` (default: 0.25)
